# 2048 Terminal Game

A terminal based implementation of the 2048 game written in C. 

## Features

- Multiple board sizes 
- Tile movement and merging
- Score tracking

## Controls

N/n - new Game
R/r - move right 
L/l - move left
U/u - move up 
D/d - move down 
E/e - exit game 



## Build 
make 

## Run
./2048 

## Clean
make clean
