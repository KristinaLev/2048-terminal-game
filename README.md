# 2048 Terminal Game

A terminal based implementation of the 2048 game written in C. 

## Features

- Multiple board sizes 
- Tile movement and merging
- Score tracking

## Controls

- `N/n` - Start a new game
- `R/r` - Move right
- `L/l` - Move left
- `U/u` - Move up
- `D/d` - Move down
- `E/e` - Exit the game



## Build 
make 

## Run
./2048 

## Clean
make clean
